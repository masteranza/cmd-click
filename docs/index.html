01 / NATIVE

Safari stays in charge.

Hold ⌘ and click an HTTP or HTTPS link. The extension stops interfering page handlers and lets Safari handle the new tab.

02 / QUIET

Normal clicks stay normal.

No toolbar to manage. No new shortcuts to learn. Download links and ordinary clicks are left alone.

03 / PRIVATE

It happens on your Mac.

No accounts, analytics, or tracking. You decide which websites the extension can run on.

A minute to set up

Enable it. Then browse.

  1. Open the app and choose Open Safari Settings.
  2. Enable Command Click Rescue in Extensions and allow access to your chosen websites.
  3. Reload the website, hold ⌘, and click a real link. You can quit the app after setup.

Requires macOS 12 or later. Safari controls whether tabs open in the foreground or background. Currently tested on Safari 27; earlier versions still need device testing before release.

A small fix, with clear limits.

Does it work on every link?

It protects genuine HTTP and HTTPS links, including links in frames and shadow DOM where Safari allows the extension. Buttons without a link destination, download links, and some scripts that run before the extension are outside its scope.

Why does it need website access?

It needs to observe your Command-click and check the link destination on the page. Safari requires website access for this. Page content and browsing history are never sent to the developer.

What if a website still overrides my click?

Check access in Safari Settings → Extensions, reload the page, and try again. If it still fails, report the page and what happened.
