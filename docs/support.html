Support

Get your click back.

Command Click Rescue is a free Safari extension for macOS. It protects native Command-click on real HTTP and HTTPS links from interfering JavaScript click handlers.

Setup

  1. Open Command Click Rescue and choose Open Safari Settings.
  2. In Safari → Settings → Extensions, enable Command Click Rescue.
  3. Allow access to the websites where you want it to work. Safari lets you choose individual sites or All Websites.
  4. Reload the page and Command-click a link.

If a link still opens in the same tab

Check that the extension is enabled and has access to that website. Reload after permission changes. The clicked element must contain a real link destination; a button that navigates only through JavaScript cannot always be protected.

If new tabs open in the foreground

Safari controls this behavior. Check Safari’s Tabs settings. The extension preserves Safari’s native action and does not force a foreground or background tab.

If the extension is missing

Open the installed app once, then restart Safari and check Extensions. A development build needs Safari’s developer setting for unsigned extensions; the eventual App Store build will not need that setting.

Try a controlled test

Open the Command-click demo to compare the extension with a page that deliberately intercepts link clicks.

Report a problem

Open a GitHub issue

Please include your macOS and Safari versions, a public example URL if possible, your website-access setting, and what happened when you Command-clicked. Avoid private URLs, account information, or screenshots containing personal data. GitHub issues are public.

Compatibility and limits

The build targets macOS 12 and later. Safari 27 has been tested. Test earlier Safari/macOS versions before relying on them. Links in frames and shadow DOM work where Safari permits content scripts; websites may run handlers before the extension is injected. Download links, ordinary clicks, and non-web URL schemes are left alone.
